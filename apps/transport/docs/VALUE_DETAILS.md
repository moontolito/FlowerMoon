# Value details

In Site & Environment / Overview, double-click any non-heading row, or select it and press Enter / **Value details**. The three headline values also open their details on double-click.

The read-only window shows the value, destination, provider links, coverage, method, inputs and available retrieval fingerprints. Long records scroll. **Copy details** copies the explanation and links. Escape closes the window. Each window is a labelled snapshot; reopen it after refreshing data or changing destination.

Temperature, humidity, air quality, deposition and corrosion explain the actual implemented calculations. The corrosion details show numerical substitution, the two contributions, category thresholds, calibration checks and the separate wet-deposition scenario. CAMS forecasts, EAC4 mixing ratios and long-term ERA5 climate statistics are distinguished. Manual entries have no attributed API origin or calculation. Missing data stays unavailable.

These details document the existing screening implementation; they do not validate ground deposition as an ISO wet-candle equivalent or specify a paint system. No scientific calculations, saved project data, map selection, truck configuration or GitHub files are changed by this feature.

Links open only when clicked. Only HTTP(S) links without credentials or query strings are accepted; request parameters and credentials are not included in the audit text.
