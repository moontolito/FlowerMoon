# Activare FlowerCutter pe GitHub Pages

Repository: https://github.com/moontolito/FlowerMoon
Ramura pentru publicare: **gh-pages**. Folder: **/(root)**.

Proprietarul repository-ului deschide:
https://github.com/moontolito/FlowerMoon/settings/pages

1. Source: **Deploy from a branch**.
2. Branch: **gh-pages**.
3. Folder: **/(root)**.
4. Apasă **Save** și așteaptă workflow-ul Pages.

Adresa estimată după publicare: https://moontolito.github.io/FlowerMoon/
Această adresă nu este declarată funcțională până la verificarea live.

Repository-ul este privat. Dacă GitHub cere schimbarea planului, Pages pentru repository-uri private necesită un plan compatibil. Nu face întregul repository public doar pentru această aplicație: el conține și alte aplicații/date. Alternativa este un repository public separat care conține numai fișierele din această ramură.

După activare, verifică într-o fereastră privată: încărcarea aplicației, Optimise layout, Export Config și importul lui, Export Excel și Export PDF.

Documentație: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
