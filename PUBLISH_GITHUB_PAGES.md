# GitHub Pages

Repository settings → Pages: **Deploy from a branch**, branch **gh-pages**,
folder **/(root)**. Site: https://moontolito.github.io/FlowerMoon/

The home page (`index.html`) lists the tools from `tools.js`. Each tool lives in
its own folder. After a change, check the site in a private window: the home
page, each tool, and each tool's exports.
