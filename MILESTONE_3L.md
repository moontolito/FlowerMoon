# Milestone 3L - Excel Reading and Analysis Report

## Goal

Add one editable operational report format for quotation engineering while
preserving every existing PDF export unchanged.

## Included

- `.xlsx` export from the multi-document dashboard;
- selected documents and the active dashboard tag filter;
- Summary, Documents, Notes and Tags worksheets;
- editable Reading Status cells with controlled dropdown values;
- editable note comments;
- notes grouped and filterable by tag;
- file hyperlinks to source PDFs and source pages;
- formula-driven summary totals and tag mention counts;
- professional white/blue layout, tables, filters and frozen headers;
- atomic local export that never modifies source PDFs.

## Export Structure

- `Summary`: project title, generated date, formula-based totals and status counts;
- `Documents`: PDF title, pages, editable status, notes and tags;
- `Notes`: one row per note/tag with highlighted text, editable comment and link;
- `Tags`: mention count and document coverage;
- `Lists`: hidden validation values.

## Excluded

- Word and HTML reports;
- synchronization of edits back into PDF Analyzer;
- embedding the PDF files inside the workbook;
- macros, cloud services or external APIs;
- changes to individual or consolidated PDF exports.
